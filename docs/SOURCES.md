# Источники и права

- **Иллюстрации товаров** (`site/assets/products/*.svg`, 16 шт.) и **favicon** — собственные материалы проекта. Рисуются кодом скриптом `tools/gen-images.mjs` (`npm run images`). Сторонних изображений, фотографий и стоков нет.
- **Чертёж на первом экране** — SVG, нарисованный вручную в `site/index.html`.
- **Иконки** — собственный набор (спрайт `<symbol>` в `site/index.html`), единый штрих 1,6.
- **Шрифты** — системные стеки (`Helvetica Neue/Arial`, `Iowan Old Style/Georgia`, `ui-monospace/Menlo`). Файлы шрифтов не распространяются, внешних шрифтов и CDN нет.
- **Код** — собственный, без сторонних библиотек в сборке.
- Бренд «ОРБИТА», товары, характеристики, цифры экспедиции «Орбита-1» и адрес `orbita.example` — вымышлены.
