# Отчёт о проверках

Среда: macOS, Node 26, Python 3.9 (бэкенд и CI — 3.12).

## Автоматические проверки

| Набор | Команда |
|---|---|
| Юнит-тесты: расчёты, корзина, промокод, хранилище, фильтры, подбор, загрузка каталога из API | `npm test` |
| Бэкенд: фильтры, поиск, сортировка, промокоды | `cd backend && python -m pytest` |
| Упаковка ZIP | `python3 tests/test_pack.py` |
| HTTP и ZIP | `python3 tests/smoke.py` |

В GitHub Actions (`ci.yml`) те же проверки идут перед каждым деплоем.

## Интерфейс

Автоматических браузерных тестов в репозитории нет. Интерфейс проверялся вручную при разработке в Chrome на 1440×900 и 390×844: каталог, корзина, промокод, подбор экспедиции, паспорт (PNG, SVG, печать), клавиатура, мобильный экран.

## Ограничения

- Интерфейс проверялся вручную и только в Chrome; Firefox и Safari не тестировались. Орбитальная точка на чертеже использует CSS `offset-path`; без его поддержки она неподвижна.
- Скринридером вручную не проверялось.
- Реальный диалог печати не открывался.
- Контраст оценён на глаз.
- Номер команды неизвестен, используется `team00`.
