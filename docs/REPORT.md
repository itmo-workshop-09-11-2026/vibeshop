## Что проверено в браузере

- 100 ₽ + 200 ₽ = 300 ₽; удаление первого → 200 ₽; второго → пусто, 0 ₽ (тестовые цены подменяют модуль каталога на уровне сети; продакшн-код не менялся).
- «Отменить» после удаления; промокод 300 → 270, повтор → 270, неверный код не меняет сумму, «Убрать промокод».
- «+»/«−» обновляют суммы; предел — остаток; минимум 1.
- Остаток ограничивает добавление отдельного товара (кнопка блокируется) и набора (частичный результат с объяснением).
- Корзина, промокод и избранное восстанавливаются после перезагрузки; ключи `team00:cart:v1`, `team00:favorites:v1`.
- Повреждённое сохранение (3 варианта) и недоступный localStorage не ломают страницу.
- Поиск + категория + сортировка вместе; пустое состояние и сброс.
- Подбор: 27 сочетаний дают разные наборы (юнит-тест), параметры меняют рекомендации, возврат сохраняет выбор, исключение позиций пересчитывает итоги, набор добавляется в корзину.
- Паспорт: PNG скачивается (валидный PNG, >20 КБ), SVG скачивается, в режиме печати виден только паспорт, PDF создаётся.
- Клавиатура: Escape, ловушка фокуса (40 нажатий Tab), возврат фокуса на кнопку в корзине, быстром просмотре, паспорте и информационных окнах; весь сценарий подбора проходит стрелками, Enter и пробелом.
- Мобильный экран 390 px: нет горизонтальной прокрутки, доступны каталог, подбор, корзина, паспорт.
- `prefers-reduced-motion`: анимации отключаются.
- Нет ошибок и предупреждений консоли, нет упавших запросов, все изображения загружены.

## Ограничения

- Проверялся только Chrome. Firefox и Safari не тестировались. Орбитальная точка на чертеже использует CSS `offset-path`; без его поддержки она остаётся неподвижной.
- Ручной проверки скринридером (VoiceOver, NVDA) не было. Есть живые регионы и подписи, но их озвучивание проверено только по разметке.
- Печать проверена эмуляцией `print` и генерацией PDF, а не реальным диалогом печати.
- Публичная ссылка не создавалась: публикация не выполнялась. Инструкция — в README (GitHub Pages, workflow уже в репозитории).
- Контрастность проверялась на глаз, без автоматического аудита.
- Номер команды неизвестен, используется `team00`.
