# Сценарий демонстрации (90 секунд)

1. **0:00 — первый экран.** Название ОРБИТА, чертёж модуля с орбитой, две кнопки. Скажите: «магазин снабжения для частных экспедиций».
2. **0:10 — «Открыть каталог».** Витрина: главный товар крупно, остальные плиткой. Введите в поиск «кр», выберите категорию «Быт», сортировку «Сначала дешёвые»; покажите счётчик «Найдено». Очистите фильтры.
3. **0:25 — быстрый просмотр.** Нажмите на «Манговые кубики невесомости»: описание, характеристики, остаток. Добавьте в избранное и в корзину (кнопка отвечает «Добавлено»).
4. **0:40 — «Собрать экспедицию».** Шаги: Марс → 14 дней → Исследования. Покажите пояснения «зачем» у каждой позиции, итоговую цену и массу. Снимите галочку с одной позиции — итоги пересчитались. Вернитесь назад: выбор сохранён; смените приоритет на «Лёгкий багаж» — набор другой.
5. **1:05 — «Добавить набор в корзину».** Откройте корзину: «+»/«−», удаление и «Отменить». Введите `ORBIT10` — скидка 10%. Повторите код и введите неверный — сумма не меняется.
6. **1:20 — «Паспорт экспедиции».** Откройте паспорт, нажмите «Скачать PNG» (или «Печать»).
7. **1:28 — мелочи.** Перезагрузите страницу: корзина и избранное на месте. Escape закрывает окна, фокус возвращается.

Совет: чтобы показать частичное добавление, добавьте вручную 3 «Набора для наблюдения за метеорами» (остаток 3), затем соберите набор «Орбитальная станция → 7 дней → Исследования».
