# ОРБИТА — снабжение за пределами Земли

Учебный интернет-магазин вымышленного бренда космического снаряжения. Покупатель выбирает направление (Луна, Марс, орбитальная станция), срок и приоритет, получает набор из реального каталога и «паспорт экспедиции». **Бренд, товары и цифры вымышлены; оплаты и сбора личных данных нет.**

Стек: чистые HTML, CSS и ES-модули. Сборщика нет: папка `site/` и есть готовая статическая сборка. Сайт работает полностью без сервера. Необязательный бэкенд на FastAPI (`backend/`) отдаёт каталог и промокоды; если он недоступен, сайт использует встроенные данные.

## Запуск

```bash
python3 main.py            # http://localhost:8000  (PORT=8001 python3 main.py — другой порт)
```
Нужен Python 3.8+ (только стандартная библиотека). Страницу нельзя открывать двойным щелчком по `index.html`: ES-модули требуют HTTP-сервера (подойдёт любой статический хостинг или Live Server).

## Сборка и ZIP

```bash
python3 main.py --pack     # создаёт shop.zip (index.html в корне архива)
```
Готовая сборка — содержимое `site/`. Публикация: GitHub Pages (папка `site/`, workflow `.github/workflows/pages.yml` уже есть) или любой статический хостинг. Все пути относительные.

## Номер команды

Задаётся одной настройкой в `site/js/config.js` (`TEAM_ID`). **Номер команды неизвестен, поэтому используется `team00`.** Ключи localStorage:

- `team00:cart:v1` — корзина и промокод;
- `team00:favorites:v1` — избранное;
- `team00:expedition:v1` — выбор в подборе (дополнительный).

Чтобы сменить номер, замените значение, например на `team07`.

## Промокод

`ORBIT10` — скидка 10% на стоимость товаров. Округляется до целого рубля, половина вверх (целочисленно: `floor((сумма·10 + 50) / 100)`). Повторное применение не увеличивает скидку, неверный код показывает сообщение, код можно убрать.

## Что реализовано

- Каталог из 16 товаров в 4 категориях; поиск по названию, категории, сортировка по популярности и цене, работают вместе; счётчик найденного; состояние «Ничего не найдено» со сбросом; избранное с сохранением; быстрый просмотр.
- Корзина: добавление, «+»/«−», удаление, очистка, «Отменить» после удаления (8 с), ограничение остатком, счётчик и сумма в шапке, пустое состояние (0 ₽), итоги со скидкой, сохранение между сессиями.
- «Собери экспедицию»: 3 шага с возвратом и сохранением выбора, рекомендации из каталога (27 различающихся сочетаний), пояснение к каждой позиции, стоимость и масса, исключение позиций, добавление набора с учётом корзины и остатков (с объяснением частичного результата).
- «Паспорт экспедиции»: SVG-карточка; PNG, SVG и печать.
- Учебное «оформление» без полей ввода; информационные окна (доставка, возврат, контакты, о проекте).
- Устойчивость: повреждённое или устаревшее сохранение отбрасывается, недоступный localStorage — работа в памяти сессии.
- Доступность: семантическая разметка, подписи полей, видимый фокус, диалоги на `<dialog>` (Escape, ловушка фокуса, возврат фокуса), озвучивание уведомлений, `prefers-reduced-motion`, состояния не передаются только цветом.

## Структура

```
site/index.html, styles.css
site/js/config.js          номер команды, промокоды
site/js/data/              каталог, данные подбора, тексты окон
site/js/core/              чистая логика без DOM: cart, promo, catalog, expedition, storage, sanitize, store
site/js/ui/                отображение: каталог, корзина, быстрый просмотр, экспедиция, паспорт, диалоги, уведомления
site/assets/products/      SVG-иллюстрации (генерируются tools/gen-images.mjs)
tests/unit/                node:test — расчёты и корзина
docs/                      источники, сценарий демо, отчёт о проверках
```

## Бэкенд (необязательный)

```bash
cd backend && python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m uvicorn app.main:app --port 8010     # http://127.0.0.1:8010/api/docs
.venv/bin/python -m pytest -q                             # тесты API
npm run export:catalog                                    # обновить backend/app/catalog.json из products.js
```
Эндпоинты: `GET /api/health`, `/api/catalog`, `/api/categories`, `/api/products` (`category`, `q`, `sort`), `/api/products/{id}`, `POST /api/promo/validate`.
